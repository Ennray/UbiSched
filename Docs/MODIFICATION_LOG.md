# iS2ROS v3.0 修改说明文档

## 1. 核心修复与优化 (v3.0)

### 1.1 绝对路径彻底消除
- **源码级**: 扫描并修复了 C++ 插件与 Python 脚本中所有硬编码的 `/home/a/` 和 `E:\` 路径。统一采用基于脚本位置或运行目录的相对路径。
- **构建级**: 移除了 `CMakeLists.txt` 中对特定 Anaconda 环境的依赖，改用 `find_package(Python3)`。

### 1.2 跨平台构建系统
- **ARM 交叉编译**: 建立了 `arm_toolchain.cmake`，支持利用本地 `mnt` (Rootfs) 进行真实的 ARM 架构编译，解决了底层 C 库和 `crti.o` 链接难题。
- **统一 Makefile**: 引入顶级 `Makefile`，支持 `make x86` (本地)、`make arm` (交叉) 和 `make deploy` (自动打包)。

### 1.3 插件加载增强
- **健壮性**: 修复了 `CapAdaptiveManager.cpp` 中的插件加载逻辑。现在支持多路径自动搜索，并在加载失败时详细打印所有尝试过的路径，极大方便了现场调试。
- **环境适配**: 修复了嵌入式环境下因 Locale 设置导致的 Python 中文编码错误。

### 1.4 算法层集成
- **路径自适应**: 强化学习模型加载逻辑改为动态寻找 `weights` 目录，支持在任何工作目录下启动。

---

## 2. 冗余清理清单
- 删除了所有 `py_stub` 相关存根文件。
- 删除了源码目录下的旧版二进制 `.so` 文件。
- 删除了过时的开发阶段临时脚本和测试代码。
